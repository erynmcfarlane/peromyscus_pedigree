This project is in collaboration with Vincent Careau at the University of Ottawa. The main goal of these scripts is to determine relatedness between individual mice caught at QUBS between 2016 and 2023.
Initial alignment and QC for these data was done by Sargon Yousefian, and the code for these bioinformatics steps can be found [here](https://github.com/sargonyousefian/peromyscus).

Preliminary analyses using [ADMIXTURE](https://doi.org/10.1101/gr.094052.109) suggest high levels of admixture between _Peromyscus leucopus_ and _P. maniculatus_, with very few pure species _maniculatus_ individuals at the site. 
This means that we need to consider how to estimate relatedness in a hierarchical sense, where individuals can have high allele sharing because they are the same species, and, within those groups, high allele sharing between of pedigree-based relatedness. The concern is that the lack of consideration of the hierarchical nature of this relatedness could lead to overestimating kinship between individuals from the same species, where genotypes are not identical by descent ([Sethuraman 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC6169378/)).

There are a number of scripts that I have used to experiment with filtering and variant calling, to see how those steps affect kinship. Those scripts are [vcf_filtering_pedigree.txt](https://github.com/erynmcfarlane/peromyscus_pedigree/blob/master/vcf_filtering_pedigree.txt), together with [relatedness_correlation.R](https://github.com/erynmcfarlane/peromyscus_pedigree/blob/master/relatedness_correlation.R) and [kinship.txt](https://github.com/erynmcfarlane/peromyscus_pedigree/blob/master/kinship.txt). My thought process is detailed in these scripts, which primarily use [vcftools](https://vcftools.github.io/man_latest.html) relatedness2 to estimate relatedness between individuals. It should be noted, as above, that this method is not optimized for populations where there is admixture.

I ran into a number of problems going straight from filtering to relatedness. The primary problem is that, because these are GBS data, even after stringent filtering, many retained individuals have very few called SNPs. While this is appropriate for population genetic analyses, it makes it difficult to estimate pairwise kinship or relatedness, as I would often be trying to estimate relatedness between individuals with no shared SNPs. 

After discussing with Alex Buerkle and Josh Jahner, I was pointed to [entropy]( https://doi.org/10.1111/1755-0998.13330) which Sargon was already using to estimate ancestry. One of the outputs of entropy is imputed genotype likelihoods for all SNPs, even when GBS data are used as inputs. 

Using the file [genoest.txt](https://github.com/erynmcfarlane/peromyscus_pedigree/blob/master/genoest.txt), which is output from one of Sargon's runs of entropy, and the script [genoest_to_plink.R](https://github.com/erynmcfarlane/peromyscus_pedigree/blob/master/genoest_to_plink.R) I made some progress to get data that could be either used in a kinship estimator, or directly in an animal model analysis. These data are saved as [genoest_calls.txt](https://github.com/erynmcfarlane/peromyscus_pedigree/blob/master/genoest_calls.txt) (to be contrasted with genotype likelihoods in genoest.txt), [genoest_calls.ped](https://github.com/erynmcfarlane/peromyscus_pedigree/blob/master/genoest_calls.ped) and [genoest_calls.map](https://github.com/erynmcfarlane/peromyscus_pedigree/blob/master/genoest_calls.map). **The problem** with these imputed data is that they are from an entropy run with 5000 SNPS that were **chosen explicitly as ancestry informative markers**. That is to say that these 5000 SNPs maximize variation between the two pure species populations while minimizing the within the two pure species populations. They will be biased for relatedness.

Sargon is currently running entropy with the 21,000 SNPs chosen without regard to ancestry. When ready, I will take the genoest file, run it through genoest_to_plink.R, and have imputed genotype likelihoods and calls ready for downstream analyses.
